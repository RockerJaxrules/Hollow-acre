# Hollow Acre

A 2D pixel-art farming game with psychological horror.

**Play it in your browser:** https://rockerjaxrules.github.io/Hollow-acre/

The game lives in `hollow-acre/2d/` (the playable build is `hollow-acre/2d/index.html`); the desktop and Android apps are in `hollow-acre/desktop/` and `hollow-acre/mobile/`.
