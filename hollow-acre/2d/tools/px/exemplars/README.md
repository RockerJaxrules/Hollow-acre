# Exemplars

My own sprites that passed the blind critique (7/10+), each with a note on why it works.

- `crop_turnip_3.png` (ripe turnip, 7/10 under the STRICT crop judge, reference set = 8, Nov 10): spoon leaves with a

  (lights near 210 lum), a soft contact shadow instead of a soil dish, darker lines where leaves overlap. Drawn in
  `crops.py` (`turnip`, `spoon`).
